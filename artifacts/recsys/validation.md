Исходная установка без ограничений версий не завершилась: свежий llvmlite требовал
сборки с CMake, а Intel macOS ограничен серией PyTorch 2.2. Добавлены платформенные
constraints. Из-за медленной загрузки pip часть wheels получена curl по ссылкам
официального PyPI JSON API, с проверкой опубликованных SHA-256, и установлена
из локального wheelhouse. Проверка TLS не отключалась. Это способ установки
на данном компьютере; обычная команда с constraints указана в инструкции.

При первом запуске один новый тест пытался читать внутреннее поле `route.path`,
которое отсутствует у нового `_IncludedRouter` FastAPI. Проверка заменена на
публичную OpenAPI-схему; окончательный набор прошёл полностью.
Единственное оставшееся предупреждение — StarletteDeprecationWarning о httpx
в TestClient, без влияния на успешные проверки.

Существующие семь API-тестов используют заглушки нейросетей. Их прохождение
подтверждает совместимость обработки запросов, а не качество реальных моделей
Hugging Face/Torchvision. RecSys отдельно проверен на настоящем MovieLens через CLI
и два запущенных HTTP-приложения; эти проверки не подменяют модель.

Не проводились: удалённый GitHub Actions, сквозной запуск старого ноутбука,
новый инференс четырёх чужих моделей, нагрузочное тестирование и production A/B-тест.
GitHub Actions изменён для будущего запуска unit-тестов и эксперимента на настоящих
данных; статус потребуется проверить после отдельно разрешённого push.
PR и сдача в ЦОР не выполнялись.
